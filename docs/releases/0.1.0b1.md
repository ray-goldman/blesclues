# BLE's Clues Beta 1 — 0.1.0b1

This is the first beta release of BLE's Clues.

## Highlights

- Added nearby Wi-Fi scan results to the Devices page, including watch-list actions for observed networks.
- Kept BLE and Wi-Fi observations in readable device cards, with Wi-Fi results visually distinct.
- Fixed Wi-Fi cards not rendering and kept the last observed Wi-Fi cards visible when a Device Scan is paused.
- Improved parsing of current `iw` scan output.
- Advanced the dashboard build label from Alpha 5 to Beta 1.

## Updates

The release includes a signed update bundle, the Python wheel, and signed manifest files. Dashboard updates require the release signing public key to be installed on the Pi. Updates remain manual: check or upload, stage, review, then apply.
