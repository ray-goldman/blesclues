# BLE's Clues Beta 4 — 0.1.0b4

This release fixes update installation on Raspberry Pi by allowing the restricted updater service to write its managed systemd units, sudoers rules, and helper scripts. Failed applications still roll back to the previous version.

Staging the same signed version again now replaces the previously staged copy. The update page and disk keep one staged bundle per version, including after a service restart.
