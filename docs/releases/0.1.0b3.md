# BLE's Clues Beta 3 — 0.1.0b3

This release fixes signed update installation. The updater now stages wheels under a pip-compatible filename derived from the verified release version. Beta 2's bundle was rolled back during installation because pip rejects the generic `artifact.whl` name; this release corrects that failure.

It also includes Beta 2's protected update trust-key directory. Existing installations should keep the verified key at `/etc/bt-signature-detector-trust/update.pub`.
