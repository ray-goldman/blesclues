# BLE's Clues Beta 6 — 0.1.0b6

Since Beta 5:

- Added named ignore lists for BLE and Wi-Fi matches. Ignore rules hide live and future matches without changing saved event history.
- Added update progress feedback that stays visible while the Pi restarts and reconnects.
- Kept Devices on the configured passive BLE scan. Pause and Resume now control only page updates, preserving the BLE and Wi-Fi results already on screen.
- Removed the temporary privileged device-browser mode and clean up its helper and sudoers assets during upgrades.
- Prevented the Updates page from offering the installed or an older build again, including staged files recovered after a restart.
