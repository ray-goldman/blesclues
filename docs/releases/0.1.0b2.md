# BLE's Clues Beta 2 — 0.1.0b2

This security update moves the updater's Ed25519 trust key into a root-owned directory outside the web service's writable configuration directory. The installer can provision a supplied public key with `UPDATE_PUBLIC_KEY`; existing installations must verify their current key through a trusted channel and install it into `/etc/bt-signature-detector-trust/update.pub` before using the updated updater.

The dashboard build label is now **Beta 2**.
