03 · RADIO MODE

Nearby Wi-Fi discovery

The Pi has one Wi-Fi radio. Scanning and the hidden admin hotspot are exclusive modes; switching modes stops the current service before starting the other.

Scans for network names and BSSIDs every 15 seconds. BLE's Clues does not join networks. Raw results stay in temporary memory and clear when scanning stops or the Pi restarts.
